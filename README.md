### Пошаговая инструкция по установке и настройке форума

1. **Установка плагина**  
   - В админке WordPress перешла в *Плагины → Добавить новый*.  
   - Нашла плагин **bbPress**, установила и активировала его.  
   - *Альтернативный способ (ручной):* скачала архив с официального сайта, загрузила в `/wp-content/plugins/` и активировала.  
   - *Скриншот:* `Скачанный плагин.jpg`

2. **Создание форума**  
   - Перешла в *Форумы → Добавить новый*.  
   - Создала форум **«Обсуждение кавказской кухни»** (описание: делимся рецептами, впечатлениями о блюдах).  
   - Опубликовала форум.

3. **Наполнение контентом (по требованиям)**  
   - **Минимум 1 форум** — создан ✅  
   - **Минимум 3 темы** — созданы ✅ (см. `темы.png`, `темы2.png`)  
   - **Минимум 3 сообщения** — добавлены ✅ (см. `Сообщения.png`)

4. **Добавление форума на сайт**  
   - Форум добавлен в главное меню сайта (раздел «Форум»).  
   - Доступен по прямой ссылке.
